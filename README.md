# 🚀 Projetos em Destaque | Featured Projects

### Domus App

Plataforma **SaaS multi-tenant de gestão ministerial** — do CRM ao financeiro, da agenda ao onboarding.

Features:

- CRM com filtros compostos e segmentação dinâmica
- Agenda com Stripe Payment Intents e check-in de presença
- Automações via BullMQ (aniversários, ausências, eventos)
- Três camadas de IA: Analytics AI, Assistente Organizacional e Pastoral AI
- Relatórios em PDF por tier de plano (Puppeteer)
- Onboarding wizard e sistema de missões
- Quatro tiers de assinatura via Stripe Billing

Stack:

```
Node.js · Express · TypeScript · MongoDB
React 18 · Vite · Tailwind CSS · shadcn/ui
Stripe · BullMQ · Redis · Anthropic API · Docker
```

---

### LJ Cookies

Sistema completo de gestão para **produção e vendas de cookies artesanais**, desenvolvido para uso real.

Features:

- controle de estoque e compras
- registro de vendas e dashboard financeiro
- sistema de notificações
- sugestão de receitas baseada no estoque
- PWA com funcionamento offline

Stack:

```
Vue · Node.js · MySQL · PWA · Docker
```
